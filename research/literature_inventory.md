## Binding source-use rules

The oracle g-formula uses the standard conditional causal-identification argument and is valid only \(P_X\)-almost everywhere. Lin is a template for the average distribution-valued problem, not a direct theorem for a forest CATE. R3D is the closest verified source on the two-layer empirical-quantile problem and must be read before an inner-sampling theorem is claimed. FOCaL applied to the unscaled augmented vector and Causal-DRF are mandatory simulation baselines. If ODCF has no nontrivial forest-by-inner-sampling result and no empirical advantage over those constructions, G0/G2 requires `PIVOT-INNER-SAMPLING` or `ABANDON`.
